# Factory maintain

Resolve the default once through the [configuration contract](../factory-setup/references/configuration.md#default-resolution-and-pinning),
unless this call already carries pinned absolute config/local from an invocation.
Reuse those paths for all helpers and artifacts; an invalid default stops with
setup/repair instructions instead of selecting another factory.

Default to PREVIEW ONLY, preserving configured cleanup: preview_only. Read the
[maintenance contract](references/maintenance.md) before classifying resources or
copying an archive. Use explicit config/runtime/resource records and read-only
inspect; do not acquire a work invocation or run intake/engineering. A directory
name or an agent's guess never establishes factory ownership.

Verify current identities, Git/owner state and actual native lifecycle capability.
Retain active/live/unknown ownership, blocked/human-wait items, dirty/staged/
untracked content, unmerged branches, unresolved actions and unrelated resources.
A merged PR alone does not complete an item. Preserve source captures, decisions,
reviews, raw evidence needed by reports and final evidence throughout the trial.
Missing observations are a reason to retain or mark unknown, not assume eligibility.
Do not terminate a process or reset/stash/overwrite code to make it removable.

Write a concise local preview listing each recorded resource, observed identity/
state, retain/archive-copy/candidate disposition, evidence and exact reason or
remaining prerequisite. Reuse an unchanged preview after fresh checks without
new duplicate artifacts. A candidate is not permission to remove it. Preserve
canonical history, engineering state, resource bytes and all earlier evidence.

Only an explicit request may create a local completed-record archive COPY/index
or restore COPY into a new inspection destination. Verify hashes and scope,
preserve originals and paths, and never replace/move/delete canonical records or
unresolved files. Archive and deletion are distinct actions.

No cleanup runs on a schedule. A later concrete user-authorized eligible list
still needs fresh state checks and an actually supported native lifecycle action;
never substitute shell deletion or delete remote branches/tickets/comments.
Keep default preview policy unchanged. This release supplies preview/copy instructions; actual native removal remains
untested until separately
requested and verified. Report capability gaps honestly.
